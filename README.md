# 💫 About Me:

### 👩‍💻 About Me

Hello! I'm **Vaishnavi Pise**, a Final-Year Computer Science & Engineering student passionate about software development, problem-solving, and creating impactful technology solutions.

💡 I enjoy building web applications and working with modern technologies such as **Java, JavaScript, React, Node.js, Express.js, MongoDB, MySQL, PHP, HTML, and CSS**.

🚀 **My projects include:**

- 📋 **HireTrack – Recruitment & Placement Management System** – A Java + MySQL layered application that manages the complete recruitment lifecycle from candidate registration and eligibility checks to interviews, offers, joining, placements, reports, and audit history.
- 💻 **Online Device Repair Tracking & Management System** – A Snehpreet Enterprise sponsored web platform for repair tracking, customer management, orders, online payments, and administrative operations.
- 🏥 **AI-Based Smart Emergency Hospital Bed Availability & Patient Routing System** – A MERN-stack application to find nearby hospitals, check bed availability, request ambulances, and recommend the best emergency hospital route.
- 🪖 **Smart Helmet Accident Detection System** – An IoT-based system for accident, alcohol, and drowsiness detection with emergency alerts.
- 🎫 **College Gate Pass Management System (GETPASS)** – A PHP & MySQL-based system for online student gate-pass requests, approvals, and administrative management.
- 🏛️ **Historical Places in Maharashtra Website** – An interactive website showcasing Maharashtra's historical and cultural places.

🏆 **Achievements:**

- Best Performance Award Winner.
- Current CGPA: 9.68/10.
- Built and delivered academic, sponsored, and self-driven projects across web, Java, AI, and IoT domains.

🎯 **Leadership Experience:**

- Serving as Training & Placement Coordinator, coordinating placement activities and connecting students with opportunities.
- Collaborating with teams on full-stack and sponsored projects from planning through delivery.

🌱 **Currently enhancing my skills in Data Structures & Algorithms, Java backend development, Full-Stack Development, and AI-powered applications.**
